# User Stories and Acceptance Criteria

## US1 Fund comparison

**Linked requirements:** FR2, FR3

As a first-time investor, I want to view the main details of two funds together, so that I can compare them without switching screens.

**Acceptance criteria**

1. Two selected funds appear in aligned rows.
2. Each fund includes a working source or document link.

## US2 Savings scenario

**Linked requirements:** FR1, FR5

As a student saving for a goal, I want to change the monthly amount and saving period, so that I can explore what I may be able to contribute.

**Acceptance criteria**

1. Updating an amount recalculates the scenario.
2. The result separates contributions from assumed growth and states the assumptions.

## US3 Eligibility and explanations

**Linked requirements:** FR4, FR6

As a cautious investor, I want to see why a fund appears in or is excluded from my comparison, so that I can understand the information used.

**Acceptance criteria**

1. An eligibility filter changes the visible list.
2. Each highlighted difference includes an explanation and a source date or missing-data notice.
